# Standards Manifest Overrides

`.ai/reference/standards.md` is **template-owned** — `upgrade-template.py` lists it in
`TEMPLATE_OWNED`, so a template upgrade restores the template's version of the manifest. This
project has diverged from it deliberately, and this file records the divergence so it is not lost
silently.

## Divergence: ISO/IEC/IEEE 29119-3:2021 is `Aligned`, not `Evidence`

**What the template declares:** row 1 is `Evidence`, proved by `.ai/tests/validate-traceability.py`,
with the evidence being `docs/slices/{BC}/{Entity}.{Operation}/test-plan.md`,
`docs/test-reports/{release}-test-completion-report.md` and
`docs/test-reports/incidents/TIR-{yyyy-mm-dd}-{NN}.md`.

**Why this project cannot keep that claim:** those artifacts do not exist here. There is no
`docs/slices/` tree and no `docs/test-reports/` directory. The manifest's rule 9 assumed the
template itself (no solution file); this repository holds `NugetPackageManager.slnx`, so
`validate-standards.py` tests the row against the evidence the project actually produces and
downgrades it.

**What was changed (2026-11-01):** the row's `Compatibility` cell is `Aligned`, its
`Proving validator` cell is `—` (a non-`Evidence` row may name none), and the row carries a
demotion sentence. Two prose lines that assumed the claim were corrected with it.

**Affected manifest lines today:** the status table under `## Compatibility`, row 1; the
`Ordered strongest claim first` sentence above it; the `validate-traceability.py` row in
`## Validators`.

## After a template upgrade

An upgrade that touches `.ai/reference/standards.md` will re-introduce `Evidence`. Re-apply the
demotion before committing the upgrade, then confirm the gate:

```bash
python .ai/tests/validate-standards.py    # must exit 0
```

If `TEST 6` reports `declared 'Evidence', computed 'Aligned'`, the demotion was lost — restore it
with the same three edits above. `COMPLIANCE.md` and the `README.md` block are `PROJECT_OWNED` and
are regenerated by the `verify-config` skill, not by the upgrade.

## When this override can be removed

Promoting the row back to `Evidence` requires producing the artifacts **and** keeping
`validate-traceability.py` green in the same change. Until a slice/test-report pipeline exists here,
`Aligned` is the honest value: the practice vocabulary is available, no audit artifact is produced.
